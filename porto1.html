Panduan singkat: SUM di Excel

Rumus SUM digunakan untuk menjumlahkan beberapa angka. Misalnya, jika angka berada pada sel A1 sampai A5, ketik rumus berikut pada sel kosong:

=SUM(A1:A5)

Tekan Enter untuk melihat hasilnya. Cobalah dengan data latihan sendiri agar kamu memahami cara kerjanya.

Panduan singkat: HTML

HTML digunakan untuk menyusun isi halaman website. Tag seperti <h1> membuat judul, sedangkan <p> membuat paragraf. Kamu bisa mencoba mengubah teks pada file index.html menggunakan VS Code.
